# ० — प्रस्तावना: निद्राको एजेन्ट टापु

यो कथा रातको लागि बनेको हो, र निदाउँदै गर्दा सुन्नका लागि हो। सुत्ने बाटोमै तिमी AI agent बनाउन र तिनलाई जाँच्न सिक्दै जानेछौ। अब आराम गर, र स्ट्रो ह्याट टोलीसँग हिँड।

समुद्र शान्त छ। छाल जहाजको पेटीमा बिस्तारै ठोक्किन्छ। माथि गन्न नसकिने तारा छन्, र हावा न्यानो छ। थाउजेन्ड सनी आफ्नै गतिमा अघि बढिरहेको छ।

@read hush
लामो श्वास लेऊ। अब बिस्तारै छोड। काँधलाई ओछ्यानमा बिलाउन देऊ। कतै पुग्नु छैन, कतै हतार छैन। कुनै टापुमा तिमी निदायौ भने अर्को रात त्यही ठाउँबाट फेरि सुरु हुन्छ।

डेकमा टोली भेला भइसकेको छ। नामीले नक्सा फिँजाइन्, र त्यसका कापहरू हावामा बिस्तारै हल्लिए।

लुफीले नक्सामा आँखा गाड्दै सोध्यो — [luffy]"नामी, आज राति कहाँ जाने हो?"[/]

[nami]"आज राति हामी चौध वटा टापु घुम्छौं।"[/] नामीले औंलाले नक्सा छोइन्। [nami]"हरेक टापुमा एउटा सीप छ। पहिलो आधा बाटोमा हामी agent बनाउँछौं। दोस्रो आधा बाटोमा हामी त्यो agent साँच्चै राम्रो छ कि छैन भनेर नाप्छौं।"[/]

@read teach
agent भनेको के हो त? एउटा LLM छ, जसले शब्द पढ्छ र शब्द लेख्छ। त्यसलाई tool दिइन्छ, र एउटा loop भित्र राखिन्छ। अब कुन tool चलाउने, र कहिले रोकिने, त्यो निर्णय loop भित्र model आफैं गर्छ। यति भयो भने त्यो agent बन्छ।

[chopper]"अनि evaluation भनेको के हो?"[/] चोपरले सोध्यो।

रोबिनले किताब बन्द गर्दै भनिन् — [robin]"evaluation भनेको नाप्ने कला हो। agent बनाउन सजिलो छ। तर त्यो राम्रो भयो कि भएन भनेर इमानदारीपूर्वक नाप्न गाह्रो छ। अन्तर्वार्तामा मानिसहरू सबैभन्दा बढी यही कुरा सोध्छन्।"[/]

[usopp]"त्यसो भए नाप्ने कुरा नै असली खजाना हो।"[/] उसोपले भन्यो।

[robin]"हो।"[/] रोबिनले टाउको हल्लाइन्। [robin]"model जति राम्रो भए पनि, नाप्न नजान्ने टोलीले आफ्नो प्रगति देख्दैन।"[/]

@read hush
सान्जीले भान्साबाट टाउको निकाल्दै भन्यो — [sanji]"जानुअघि नक्साका सबै टापुको नाम एकपटक सुन। नाम सुनिसकेपछि बाटो आफैं चिनिन्छ।"[/]

@algo naksa
हाम्रो नक्सामा चौध टापु छन्, र क्रम यही हो। पहिलो टापुमा LLM API, token, sampling र context window छन्। दोस्रोमा prompt र structured output छन्। तेस्रोमा tool use र agent loop छ। चौथोमा ReAct जस्ता agent architecture छन्। पाँचौंमा RAG छ। छैटौंमा workflow, orchestration र MCP छन्। सातौंमा coding agent छन्। आठौंमा evaluation को जग र pass@k छ। नवौंमा benchmark र contamination छन्। दसौंमा LLM judge छ। एघारौंमा statistics छ। बाह्रौंमा ठूलो मात्राको eval infrastructure छ। तेह्रौंमा agent को evaluation छ। चौधौंमा सबै जोडेर बनेको eval harness छ।
@end

[zoro]"धेरै छन्।"[/] जोरोले आँखा चिम्लँदै भन्यो।

[nami]"धेरै देखिन्छन्, तर एउटै कथा हो।"[/] नामीले भनिन्। [nami]"पहिले हामी बोल्ने मेसिन बुझ्छौं। त्यसपछि त्यसलाई हात दिन्छौं। त्यसपछि त्यसलाई सम्झना दिन्छौं। अन्त्यमा त्यसको परीक्षा लिन्छौं।"[/]

@read teach
हरेक टापुमा एउटा विधि छ, र त्यो विधि म तीन पटक भन्छु। पहिलो पटक सिकाउनका लागि भन्छु। दोस्रो पटक कथाको बीचमा भन्छु। तेस्रो पटक टापु छाड्नुअघि भन्छु। एउटै शब्द तीन पटक सुन्दा त्यो मनमा बस्छ, र अन्तर्वार्तामा त्यही शब्द तिम्रो मुखबाट आफैं निस्कन्छ।

@recall naksa | नक्साका टापु फेरि एकपटक सुन, बिस्तारै।

ब्रुकले भायोलिन काँधमा राख्यो, र एउटा मधुरो धुन बजायो। फ्र्याङ्कीले जहाजको पाल मिलायो। जिम्बेले पतवार समात्यो, र जहाज पहिलो टापुतिर मोडियो।

@read hush
तिमी केही गर्नु पर्दैन। बस सुन। बुझ्ने काम निद्राले आफैं गर्छ।

@recall naksa | पहिलो टापु आउनुअघि नक्सा अन्तिम पटक सुन।

@tier medium

रोबिनले एउटा पुरानो कुरा सुनाइन्। उनले भनिन् — [robin]"धेरै अघि मानिसहरू model लाई प्रश्न सोधेर एउटा उत्तर मात्र लिन्थे। अहिले model ले आफैं कोड चलाउँछ, फाइल खोल्छ, र वेबमा खोज्छ। काम ठूलो भएपछि गल्ती पनि ठूलो हुन्छ, त्यसैले नाप्ने काम झन् जरुरी भयो।"[/]

[franky]"त्यसो भए यो यात्राको अन्त्यमा हामी के बनाउँछौं?"[/] फ्र्याङ्कीले सोध्यो।

[robin]"एउटा agent र त्यसको harness बनाउँछौं।"[/] रोबिनले भनिन्। [robin]"harness भनेको त्यो मेसिन हो जसले agent लाई सयौं काम दिन्छ, हरेक काम जाँच्छ, र अन्त्यमा इमानदार अङ्क दिन्छ।"[/]

@tier long

रात गहिरिँदै गयो। जहाजको डेकमा लालटिन मधुरो बलिरहेको थियो। लुफी मस्तुलको फेदमा टाउको अड्याएर सुतिसकेको थियो।

चोपरले नक्साको किनारमा सानो चिन्ह कोर्यो, र भन्यो — [chopper]"म हरेक टापुमा एउटा तारा बनाउँछु।"[/]

@read hush
तिमी पनि आफ्नो मनमा तारा बनाऊ। एउटा टापु सकियो भने एउटा तारा बल्छ। सबै तारा बलेपछि तिमीसँग पूरा आकाश हुन्छ।
