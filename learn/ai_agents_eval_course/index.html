AI Agents & Evaluation

Interview prep for building LLM and agent workflows and running large-scale evaluations. It begins with the API basics (tokens, sampling, structured output, tool use) and writing the agent loop yourself. Then come agent architectures, RAG, orchestration and coding agents. The evaluation half covers metrics and pass@k, the benchmark landscape and contamination, LLM-as-judge, the statistics that separate a real improvement from noise, and the infrastructure that runs thousands of sandboxed evals in parallel.

Every lesson has the real mechanics, a One Piece story that acts the idea out (plus a sitcom scene), an interactive walkthrough, a code lab, a quiz, and the interview questions with strong answers. Flip Essentials → Full Depth in the header for the deeper material. There is also a 🌙 Nepali bedtime voyage that tells the whole syllabus as one night at sea.

How to use this

  1. Build first, then measure. Parts 0–1 build agents, and Parts 2–3 cover how you would know whether one is any good, which is where most interview depth lives.
  2. In each lesson, read the concept and click through the interactive walkthrough. Do the Code Lab in the browser, then run it for real. Answer the interview questions out loud before you open them.
  3. Setup: Python 3.10+, pip install anthropic (or any provider SDK), an API key, and Docker for the sandboxing labs.
  4. Keep the Cheat Sheet open in a second tab, and finish with the timed Interview Drill.
  5. The night before: put on the 🌙 bedtime voyage.
