Compilers & Program Analysis

Interview prep for roles that ask for a compilers and program-analysis background. It runs from tokens and grammars, through hands-on AST work (Python's ast, JavaParser, tree-sitter, srcML), to lowering into IRs (three-address code, CFGs, SSA, LLVM IR, Soot/SootUp Jimple). From there it covers the theory every analysis rests on (dataflow, lattices, abstract interpretation, pointer analysis, taint) and the analyzers people use day to day in Java and Python. The capstone is a mini analyzer you build end to end.

Every lesson has the real mechanics, a One Piece story that acts the idea out (plus a sitcom scene), an interactive walkthrough, a code lab, a quiz, and the interview questions with strong answers. Flip Essentials → Full Depth in the header for the deeper material. There is also a 🌙 Nepali bedtime voyage that tells the whole syllabus as one night at sea.

How to use this

  1. Parts 0–2 build the pipeline: parse → AST → IR. Part 3 is the theory interviewers probe, and Part 4 maps it onto real tools (SpotBugs, Infer, Error Prone, mypy, Semgrep, CodeQL).
  2. In each lesson, read the concept and click through the interactive walkthrough. Do the Code Lab in the browser, then run it for real. Answer the interview questions out loud before you open them.
  3. Every lab is meant to be run for real. You need python3 (the ast module is built in), pip install tree_sitter, a JDK 17+ for JavaParser/SootUp, and the srcML CLI.
  4. Keep the Cheat Sheet open in a second tab, and finish with the timed Interview Drill.
  5. The night before: put on the 🌙 bedtime voyage.
