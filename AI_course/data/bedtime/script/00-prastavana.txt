# ० — प्रस्तावना: पोनेग्लिफको नक्सा

जहाज बन्दरगाहमा उभिएको छ। रात शान्त छ। पानी कालो छ, र त्यसमा बत्तीका लामा धर्का हल्लिरहेका छन्।

आज कतै जानु छैन। आज केवल नक्सा हेर्नु छ, र नक्सा हेर्नु पनि यात्राकै भाग हो।

रोबिन डेकको छेउमा बसेकी छिन्। उनको काखमा एउटा ढुङ्गाको टुक्रा छ, र त्यसमा कसैले धेरै वर्षअघि केही कोरेको छ। उनले भनिन् — [robin]"मानिसहरू यसलाई ढुङ्गा भन्छन्। म यसलाई वाक्य भन्छु।"[/]

त्यही एउटा वाक्यमा यो पूरै course बस्छ। चिन्ह ढुङ्गामा छन्, र अर्थ ढुङ्गामा छैन। अर्थ पढ्न जान्नेको टाउकोमा छ। मेसिनलाई पढ्न सिकाउनु भनेको चिन्हबाट अर्थ निकाल्न सिकाउनु हो।

@read teach
अब पहिलो अलमल हटाऔं, किनभने यी शब्दहरू सबैतिर मिसिएर आउँछन्। सबभन्दा बाहिरको छाता artificial intelligence हो। यसभित्र कम्प्युटरलाई बुद्धिमान् देखिने काम गराउने जुनसुकै तरिका पर्छ। पुरानो chess खेल्ने program पनि यसैभित्र पर्छ, र त्यसमा कुनै सिकाइ थिएन।

त्यो छाताभित्र एउटा सानो घेरा छ, र त्यसलाई machine learning भनिन्छ। यहाँ नियम मानिसले लेख्दैन। नियम data बाट आफैं निस्किन्छ। तपाईंले spam चिन्ने नियम लेख्नुहुन्न। तपाईंले दस हजार spam र दस हजार साँचो चिठी देखाउनुहुन्छ, र मेसिनले नियम आफैं भेट्टाउँछ।

अब एउटा कुरा ध्यान दिनुहोस्, किनभने यही यो course को जग हो। मेसिनले भेट्टाएको नियम शब्दमा हुँदैन। त्यो नियम केवल number हो। ती numberहरूलाई weight भनिन्छ, र तिनलाई data सँग मिलाउन घुमाउनु नै training हो।

machine learning भित्र अझ सानो घेरा छ, र त्यसलाई deep learning भनिन्छ। यहाँ model धेरै तह भएको neural network हुन्छ। विचार उही हो, तर number लाखौं वा अरबौं हुन्छन्, र ती तह तहमा बसेका हुन्छन्। यति धेरै number भएपछि model ले आफ्नै feature आफैं सिक्छ।

अब NLP कहाँ पर्छ भन्ने प्रश्न आउँछ। NLP कुनै घेराभित्र पर्दैन, किनभने त्यो घेरा होइन, काम हो। NLP भनेको कम्प्युटरलाई मानव भाषा सम्हाल्न लगाउने काम हो। यो काम पहिले classical machine learning ले गर्थ्यो, र अहिले deep learning ले गर्छ।

large language model यी दुईको जोडमा बस्छन्। तिनी ठूला deep learning का transformer हुन्, र तिनलाई एउटै काममा तालिम दिइएको हुन्छ। त्यो काम अर्को token अनुमान गर्नु हो। GPT, Claude, Gemini र Llama सबै त्यही एउटै जातका हुन्।

अन्तिममा agent आउँछ, र यहाँ धेरै मानिस अल्झिन्छन्। agent model होइन। agent तपाईंले लेख्ने program हो, र त्यसले model लाई घुमाइफिराइ बोलाउँछ। बीचमा त्यसले tool चलाउँछ, र फर्केको जवाफ फेरि model लाई देखाउँछ। model engine हो, र agent त्यसवरिपरि बनाइएको गाडी हो।

लुफीले हाई गर्दै सोध्यो, [luffy]"त्यसो भए हामीले सिक्ने के हो?"[/] रोबिनले ढुङ्गामा औंला राखिन्।

अब यो टापुको सार सुन्नुहोस्, र यो आज तीन पटक फर्केर आउनेछ।

@algo char-ghera
यी चार शब्द यसरी बस्छन्। artificial intelligence सबभन्दा बाहिरको छाता हो, र यसभित्र बुद्धिमान् देखिने जुनसुकै तरिका पर्छ। machine learning त्यसभित्रको घेरा हो, र यहाँ नियम data बाट आउँछ। deep learning त्यसभित्रको सानो घेरा हो, र यहाँ model धेरै तह भएको network हुन्छ। large language model त्यही तेस्रो घेराभित्र बस्छन्, र तिनले अर्को token अनुमान गर्न सिक्छन्। agent घेराभित्र पर्दैन, किनभने agent model लाई बोलाउने program हो।

यति चिनेपछि कुनै पनि लेख पढ्दा तपाईं अल्मलिनुहुन्न। हरेक नयाँ नामलाई यी चार घेरामध्ये कुनै एउटामा राख्न सक्नुहुन्छ।

आँखा चिम्लिएकै अवस्थामा एकपटक, हल्का गरी, ती चार घेरा फेरि सुन्नुहोस्।

@tier medium

रात अझै लामो छ। रोबिनले अर्को कुरा सुनाइन्, र त्यो model शब्दकै बारेमा थियो।

[robin]"मानिसहरू model लाई रहस्य ठान्छन्। model रहस्य होइन।"[/] उनले भनिन् कि model भित्र घुमाउन मिल्ने number भएको एउटा function मात्र हो।

सबभन्दा सानो model सुन्नुहोस्। त्यो f of x बराबर w गुणा x जोड b हो। यहाँ घुमाउन मिल्ने number दुई मात्र छन्, र ती w र b हुन्। यो पनि model हो।

सबभन्दा ठूलो model पनि उही जात हो। त्यहाँ घुमाउन मिल्ने number खरबौं हुन्छन्, र function को आकार धेरै जटिल हुन्छ। तर वर्ग उही हो।

अब training के हो भन्ने सुन्नुहोस्, र यो पाँच कदमको एउटै चक्र हो। पहिलो कदममा data र model लिइन्छ। दोस्रो कदममा जवाफ कति गलत छ भनेर नापिन्छ, र त्यो नापलाई loss भनिन्छ। तेस्रो कदममा हरेक number कतापट्टि घुमाउँदा loss घट्छ भनेर हिसाब गरिन्छ, र त्यो हिसाबलाई gradient भनिन्छ। चौथो कदममा हरेक number अलिकति त्यतै घुमाइन्छ। पाँचौं कदममा यो सबै फेरि दोहोरिन्छ।

यो पाँच कदम यो पूरै course हो। सानो model मा यो दुई number सँग चल्छ। ठूलो model मा उही चक्र लाखौं number सँग चल्छ। कथा उही हो, र number मात्र बढी हुन्।

त्यसैले कसैले model download गर भन्दा, तिनले ती numberहरूका मान download गर्नु भनेका हुन्छन्। ठूलो file भित्र सिकिएका number मात्र हुन्छन्, र सँगै function को आकार बताउने थोरै code हुन्छ।

रोबिनले टाउको हल्लाइन्। [robin]"हुँदैन। त्यो file database होइन।"[/]

यो कुरा सम्झनलायक छ। model भित्र तथ्यको कुनै table हुँदैन। ज्ञान अरबौं weight मा फिँजिएको हुन्छ, र फिँजिँदा केही कुरा हराउँछ।

यही कारणले model ले कहिलेकाहीं नभएको कुरा भन्छ, र त्यसलाई hallucination भनिन्छ। model ले राखेको तथ्य पढ्दैन। model ले सम्भावित जवाफ फेरि बनाउँछ।

यो बुझ्नुभयो भने पछि आउने आधा समस्या पहिल्यै बुझिन्छ। RAG किन चाहिन्छ भन्ने पनि यहीँबाट निस्किन्छ।

नामीले नक्सा बेरेर राखिन्। जहाज उही ठाउँमा उभिएको छ, र भोलि पहिलो टापु आउँछ। त्यो टापुमा तीर हुन्छन्।
